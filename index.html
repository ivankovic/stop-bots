stop-bots

A TUI and a CLI that help you configure your server to stop bad bots without hiding behind a CDN.

GitHub README Releases crates.io

What it does

  • In your web server. Blocks known bots by category (scanners, AI crawlers, search engines) with a rule it writes into your NGINX or Apache site configs.
  • From your logs. Reads the access and SSH logs and blocks addresses that scan, probe for /.env, send exploits or fake being Googlebot, each with the log line that caused it.
  • In your firewall. Writes an nftables or iptables script for those blocks, and for countries, reputation feeds and hosting providers if you want them.

One local binary. No account, no cloud service, and nothing about your traffic is sent anywhere.

Built not to surprise you

  • Every apply shows what would change first; on the CLI, --dry-run --diff.
  • Addresses that recently logged in over SSH are never blocked, an apply that would cut off a connected SSH client is refused, and a config that fails nginx -t is put back.
  • sudo stop-bots uninstall all takes it all back out.

Install

On Debian or Ubuntu:

curl -fsSL https://ivankovic.github.io/stop-bots/key.gpg \
  | sudo tee /usr/share/keyrings/stop-bots.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/stop-bots.gpg] \
https://ivankovic.github.io/stop-bots stable main" \
  | sudo tee /etc/apt/sources.list.d/stop-bots.list

sudo apt update
sudo apt install stop-bots

Installing starts nothing. Then sudo stop-bots opens the TUI, and the quick start covers the rest.

What the package contains

  • /usr/bin/stop-bots, statically linked against musl, so it depends on no system library and installs on any Debian or Ubuntu still receiving updates. amd64 and arm64.
  • Nothing scheduled. Run sudo stop-bots install cron --dry-run when you want the detectors running unattended; it prints the plan before writing anything.

Verifying it yourself

Every index is signed with the key above, and apt checks that signature on each update. To look at the fingerprint before trusting it: 

curl -fsSL https://ivankovic.github.io/stop-bots/key.gpg | gpg --show-keys

Other ways to install

  • cargo install stop-bots, with Rust 1.88 or newer.
  • A static binary for x86_64 or aarch64 Linux from the releases page, for a machine you would rather not add a repository to.

Tested on Debian and Ubuntu with systemd, and NGINX or Apache.
