stop-bots APT repository

Debian and Ubuntu packages for stop-bots — a TUI, web UI and CLI that help you stop bad bots without hiding behind a CDN.

Install

curl -fsSL https://ivankovic.github.io/stop-bots/key.gpg \
  | sudo tee /usr/share/keyrings/stop-bots.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/stop-bots.gpg] \
https://ivankovic.github.io/stop-bots stable main" \
  | sudo tee /etc/apt/sources.list.d/stop-bots.list

sudo apt update
sudo apt install stop-bots

What you get

  • /usr/bin/stop-bots — statically linked against musl, so it depends on no system library and installs on any Debian or Ubuntu still receiving updates.
  • amd64 and arm64.
  • No service. Installing the package starts nothing: run sudo stop-bots install web --dry-run when you want the console, and it prints the whole plan before writing anything.

Verifying it yourself

Every index is signed with the key above, and apt checks that signature on each update. To look at the fingerprint before trusting it: 

curl -fsSL https://ivankovic.github.io/stop-bots/key.gpg | gpg --show-keys

Other ways to install

  • cargo install stop-bots from crates.io.
  • A static tarball on the releases page, for a machine you would rather not add a repository to.
  • Arch: stop-bots or stop-bots-bin on the AUR.
